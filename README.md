# Odin Recipes

## About
This is a recipe website I created while learning HTML. It contains several recipes and demonstrates fundamental HTML concepts such as headings, links, images, lists and page structure.

## Recipes
- [Orange Cake](recipes/orange-cake.html)
- [Chocolate Cake](recipes/chocolate-cake.html)
- [Beef Samosas](recipes/samosa.html)

## Technologies
- HTML

## What I learned
- Creating and structuring HTML pages
- Working with links and images
- Creating ordered and unordered lists
- Organizing files within a project
- Using Git and Github for version control

## How to Run
1. Open `index.html` in your web browser

2. To run the project using a local server:
```bash
python3 -m http.server
```
Then open `http://localhost:8000` in your browser
